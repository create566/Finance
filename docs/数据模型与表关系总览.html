6. MongoDB 集合与 MySQL 的关系

库 ww_finance_ai @ mongodb://localhost:27017，由 finance-ai 独占读写。当前有效实现在 Mongo 这一侧；MySQL 的同名两表是迁移前的旧实现，前端零引用。

集合文档数字段作用
chat_session21_id(Long 手写自增), userId, userPhone, userName, title, messageCount, modelName, kbName, status, createTime, updateTime, _class一个客服会话一行；_id 采用 Long 而非 ObjectId，由手写 AtomicLong 自增
chat_message56_id(ObjectId), sessionId, userId, role, content, createTime, _class逐条问答；role 分布 user 28 / assistant 28；靠 sessionId 关联，无 chunk_ids 字段
两套客服实现的取舍：改客服功能请改 Mongo 那条链路。删除会话的级联（删 chat_message + chat_session + 清 chat_memory 两条 key）已收敛在 MongoSessionHistoryService.deleteSession(id)。用户端删除先做归属校验，管理端删除无归属校验。
